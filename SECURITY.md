# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security issues or sensitive bugs directly to the maintainers or via a private GitHub Security Advisory. Do not file public GitHub issues for critical vulnerabilities.

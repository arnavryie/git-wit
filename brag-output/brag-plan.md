# /brag Plan: Project Ronin (git-wit)

## Planning Rubric

1. **What is the app?**
   Project Ronin is the social intelligence layer for open-source developers — GitHub meets Twitter — powered by Gemini AI and MongoDB Atlas Vector Search.

2. **What is the funniest or most impressive claim?**
   "The social layer GitHub never built. Developers discover repos through Twitter chaos, not GitHub Explore."

3. **What is the visual hook?**
   Sleek dark GitHub palette (`#0d1117`, surface `#161b22`, border `#30363d`) with glowing purple/blue gradients, neon fork velocity badges (`🔥 +310 forks in last 24h`), and Gemini AI intelligence chips.

4. **What should be shown from the actual UI?**
   - The hero statement: "The social layer GitHub never built."
   - The Breakout Repo Radar card (`ollama/ollama`, fork velocity spike, AI insights chip, semantic stack match).
   - Developer Dossier & personalized recommendation feed highlights.

5. **What is the shortest satisfying video?**
   18 seconds.

6. **What tone fits best?**
   `polished` — clean, punchy, confident product launch video.

7. **What should the audio feel like?**
   Punchy, modern tech beat (`happy-beats-business-moves-vol-10-by-ende-dot-app.mp3`) with clean UI clicks and a smooth outro fade.

8. **What should the share caption say?**
   "The social layer GitHub never built. Discover breakout repos before they blow up with Project Ronin — GitHub meets Twitter, powered by Gemini AI & MongoDB Atlas."

9. **What's the user flow worth showing?**
   The Problem (Twitter chaos) → The Reveal (Project Ronin) → Breakout Repo Radar (Fork velocity + AI insights) → Developer Dossier → Outro.
